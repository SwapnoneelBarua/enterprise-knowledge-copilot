# enterprise-knowledge-copilot

A starter scaffold for an enterprise AI support and knowledge copilot. The planned application will help employees find internal troubleshooting guidance, cite supporting source documents, and clearly identify when the knowledge base does not contain an answer.

## Project structure

- `app/` — API, authentication, ingestion, retrieval, agents, evaluation, and observability
- `frontend/` — user interface
- `tests/` — unit, integration, security, and evaluation tests
- `evals/` — evaluation questions and benchmark tooling
- `configs/` — application configuration
- `scripts/` — development and operations scripts
- `.github/workflows/` — CI workflows

This repository currently contains only the initial project scaffold; application code and runtime configuration have not been added yet.
